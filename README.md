## Descripcion general
El proyecto permite calcular el monto final de una inversión considerando el capital inicial y el tiempo transcurrido.
utiliza la clase Fecha para trabajar con fechas y la clase TiempoDeInversion para solicitar los datos y realizar los cálculos.

## Estructura del proyecto

Proyecto/
│
├── src/
│   ├── Fecha.java
│   └── TiempoDeInversion.java
│
├── docs/
│   └── Documentación generada con JavaDoc
│
└── README.md

## Forma de compilar y ejecutar

### Compilar:
Desde la carpeta principal del proyecto:
javac Fecha.java 
javac TiempoDeInversion.java

### Ejecutar
java TiempoDeInversion
